## How I approach a project

1. Agree on the important workflows, expected behavior, and test scope.
2. Build readable tests with suitable test data and isolated execution.
3. Integrate the agreed checks into CI and document reproducible failures.
4. Hand over run instructions, coverage notes, and remaining manual checks.
